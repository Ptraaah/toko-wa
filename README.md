# toko-wa

Template toko online satu file: katalog produk cantik di HP, keranjang belanja, dan checkout yang mengirim pesanan rapi ke WhatsApp Anda. Tanpa server, tanpa database, tanpa biaya bulanan.

Dibangun untuk warung, toko kelontong, UMKM, dan siapa pun yang jualan lewat WhatsApp tapi capek mencatat pesanan satu satu dari chat.

## Fitur

- Katalog produk dengan foto, kategori, dan kotak pencarian
- Keranjang belanja dengan atur jumlah per produk
- Checkout sekali tap: pesanan terformat rapi (produk, jumlah, total) terkirim ke WhatsApp toko, lengkap dengan kolom nama dan alamat untuk pembeli
- Harga otomatis format Rupiah
- Tampil bagus di HP, satu file HTML saja

## Cara pakai

1. Fork atau unduh repo ini (atau ambil file zip dari halaman Releases).
2. Buka index.html, ganti isi CONFIG: nama toko, nomor WhatsApp (format 62xxxxxxxxxx), dan daftar produk Anda (nama, harga, foto, kategori, deskripsi).
3. Publikasikan gratis ke GitHub Pages, Netlify, atau Cloudflare Pages. Satu file ini saja cukup.
4. Bagikan tautannya ke pelanggan. Selesai, pesanan masuk ke WhatsApp Anda.

## English summary

A free single-file online store template for WhatsApp sellers: product catalog with categories and search, a working cart, and one-tap checkout that sends a neatly formatted order to the shop's WhatsApp. Edit the CONFIG block, deploy to any static host, share the link. No backend, no monthly fees.
